# NobuCare - Application de Gestion Digitale des Services Hôteliers avec Chatbot intégré et accès via QR Code

## Description
NobuCare est une application web accessible via QR code, conçue pour digitaliser les services hôteliers au Nobu Hotel Marrakech. Elle intègre un chatbot pour une assistance immédiate et inclut un système de recommandations dans le menu pour améliorer l'expérience utilisateur. Une fonctionnalité de conversion voix-texte est également ajoutée pour faciliter les interactions. L'application se divise en deux sections : une pour les clients (commandes de room service, réservations au restaurant ou spa) et une pour l'administration et le personnel (gestion des commandes, réservations, rapports en temps réel et paramètres du système).

## Fonctionnalités
### Côté Client (Invités)
- Commande de services comme le room service avec recommandations personnalisées.
- Réservation de table au restaurant ou de soins au spa.
- Interaction avec un chatbot pour une assistance instantanée via texte ou voix (voice-to-text).
- Accès simplifié via QR code.

### Côté Administration et Personnel
- Gestion des commandes et réservations avec suivi en temps réel.
- Génération de rapports personnalisés.
- Supervision des activités et gestion des paramètres du système.
- Authentification sécurisée pour les accès.

## Technologies Utilisées
- **Backend** : Java, Spring Boot (pour une architecture robuste), JWT et HTTPS (pour la sécurité).
- **Frontend** : React.js, HTML, CSS, Bootstrap, JavaScript (pour une interface responsive).
- **Base de Données** : MySQL (avec XAMPP pour le développement local).
- **Chatbot** : Dialogflow (pour un chatbot intelligent avec voice-to-text via Web Speech API).
- **Méthodologie** : Agile avec SCRUM (développement itératif, sprints, tests fréquents).

## Prérequis
- Java JDK 8 ou supérieur.
- Node.js et npm pour le frontend React.
- MySQL Server (via XAMPP ou indépendant).
- Navigateur compatible avec Web Speech API.
